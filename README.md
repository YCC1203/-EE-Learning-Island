# 電機探索島｜海大電機互動式課程地圖

這是一個**非官方、純前端互動示範作品**，以「迷你島嶼探索」呈現國立臺灣海洋大學電機工程學系大學部的課程結構。視覺互動概念參考 HEART 政策島的「島嶼／角色／探索／清單」形式，但所有圖像、角色造型、版面與程式碼均重新設計，不複製原站素材。

## 開始使用

- 直接以 Edge、Chrome、Safari 等瀏覽器開啟 `index.html` 即可。
- 若要架設 GitHub Pages，將本資料夾內的 `index.html`、`styles.css`、`app.js` 放在網站根目錄；GitHub Pages 設定從根目錄發佈。
- 無需安裝 Node.js、套件、API 金鑰或後端。地圖圖像使用原創 SVG，無外部圖片依賴。

## 互動功能

- 四座年級島：點選大一～大四島嶼、島上學生或年級按鈕，切換對應課程。
- 系主任導覽：點選中央系主任、系主任聊天按鈕，或按「下一站」依年級走訪。
- 課程詳情與探索足跡：點擊課程名稱可開啟概念介紹，探索足跡會儲存在**這台裝置的瀏覽器**（localStorage），不會上傳伺服器。
- 六大專業領域：點選卡片了解簡要方向；關聯課程僅供探索示意。
- 課程索引：可搜尋或篩選年級。
- 輔系指南：展開輔系科目表、科目代碼、學分與順序備註。
- 日夜場景：白天、黃昏、夜晚切換。
- 自適應排版：手機可以水平滑動島嶼地圖。

## 請確認的原始資料差異

- 「六選三／六選四」：共同／核心總圖標示「六選三（必選）」，按年級的關聯圖標示「六選四（必選）」。本頁不自行判定哪一份是有效版本。
- 輔系最低學分：輔系表標示至少應修 **25 學分**，但所列主要八門課、每門 3 學分，合計 **24 學分**；請向系辦查證。
- 輔系工程數學：表中另列非授予工學士者須加修工程數學 (I) 與 (II)，合計 6 學分。
- 網站中的個別課程介紹、角色對話及各領域關聯示例是為互動導覽而寫的解說，**非官方授課大綱、最新開課表或必選修清單**。
